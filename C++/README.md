# Kryptos

[KRYPTOS](https://en.wikipedia.org/wiki/Kryptos) is a currently unsolved cipher located in the CIA Headquaters in Langley, Virgina. The files in this repository show my processes of using different methods to crack this unsolved cipher using the programming language C.

K1.cpp and K2.cpp show my process for learning how the Vigenère Cipher works.<br />
K3.cpp shows my process of learning how the Transposition Cipher works.

K4.cpp is my process of learning how to automate different methods for cracking the unsolved section of the cipher.
