# Kryptos

[KRYPTOS](https://en.wikipedia.org/wiki/Kryptos) is a currently unsolved cipher created by Jim Sanborn located in the CIA Headquaters in Langley, Virgina. The files in this repository show my processes of using different methods to crack the unsolved cipher.

An auction has been announced for the solution to K4 to take place on November 20th, and the solution has been discovered in files donated to The Smithsonian Museum by Sanborn.

I will continue to work to find the solution before it gets revealed. If the solution does get revealed, I will work to find the means to obtain the solution.
